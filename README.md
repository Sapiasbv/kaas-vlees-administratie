# Kaas & Vlees administratie

Voorraad- en koppeladministratie voor kaas, vlees en vleeswaren (Sapias / Bondigro, Bonaire): RetailEdge, weegschaal en PICS-import op één lijn.

- `docs/HANDOVER.md`: volledige overdracht (context, regels, stand van zaken, open punten, plan).
- `CLAUDE.md`: werkafspraken voor Claude Code.
- `config/mapping_rules.json`: naamgeving, vendor-mapping, afdelingen en klassen.
- `legacy_scripts/`: scripts uit de eerste fase (referentie, nog te herschrijven).
- `src/`: hier komt de applicatie.
- `data/`: lokale bronbestanden (niet in git).

Huidige scope: vlees en vleeswaren. Kaas werkt al met het PICS-tool en wordt later meegenomen.

Map op de computer: `C:\Claude\Kaas & Vlees administratie`. Voorgestelde GitHub-naam: `kaas-vlees-administratie` (privé).

Start: `pip install -r requirements.txt`, zet de bronbestanden in `data/` en open Claude Code in deze map.
